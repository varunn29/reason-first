# Pre-recorded Teacher Voice Audio Clips

Place `.mp3` audio files in this directory matching the keys defined in `phrases.json`:

- `phrase_opener_01.mp3` - "शाबाश! आपने जो उत्तर दिया, वह कैसे सोचा? मुझे समझाओगे?"
- `phrase_probe_numerator.mp3` - "अच्छा प्रयास! 2/6 उत्तर मिला, ऊपर वाले नंबरों के साथ क्या किया?"
- `phrase_probe_denominator.mp3` - "बहुत अच्छे! समझ गया। और नीचे वाले 2 और 4 के साथ क्या किया?"
- `phrase_probe_rule.mp3` - "शाबाश! क्या भिन्न में नीचे वाले नंबर भी हमेशा जुड़ते हैं?"
- `phrase_closing_01.mp3` - "बहुत बढ़िया समझाया राहुल! चलो अब मिलकर इसका सही तरीका सीखते हैं।"
- `phrase_encouragement_01.mp3` - "बहुत अच्छा प्रयास! चलो मिलकर समझते हैं।"
- `phrase_fallback_subtraction.mp3` - "शाबाश! क्या आपने इकाई में घटाने के लिए दहाई से उधार लिया था?"

> **Note:** If an audio file is not present, the app automatically falls back to browser Text-to-Speech (TTS) or displays the text without crashing.
